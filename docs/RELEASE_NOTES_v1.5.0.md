# MCA Brain System v1.5.0 发布说明

发布日期：2026-04-25

## 这次版本做了什么

v1.5.0 聚焦三件事：
- 启动流程可信化：避免“显示已启动但模型未就绪”的假成功状态。
- 交互反馈清晰化：界面状态、分析进度、异常提示更一致。
- 渲染诊断细化：从泛化提示升级为更可执行的分层建议。

## 主要变化

### 1) 启动与模型就绪
- AI 初始化阶段增加语义引擎预热与就绪校验。
- 启动状态只在模型真正可用时标记为已就绪。
- 启动失败会返回明确原因，避免模糊提示。

### 2) 界面与状态反馈
- 工具栏状态提示与分析流程联动。
- 分析中、完成、失败三类状态更容易区分。
- “启用语义分析”流程与状态显示更直接。

### 3) 渲染崩溃诊断增强
- 增加覆盖层/注入冲突识别（如图形叠加冲突）。
- 增加 Vulkan 窗口占用冲突识别。
- 增加驱动模块崩溃、设备丢失、Shader 链接失败等模式。
- 对渲染模组组合冲突提供更明确的排查动作。

## 修复项

- 修复模型可用性误报链路。
- 修复 InvalidInjectionException 场景被通用候选误导的问题。
- 修复部分重复模组识别中的误报噪声。

## 使用建议

- 升级后建议先用一份已知样本日志做基线复核。
- 若渲染类问题仍复现，优先按“覆盖层冲突 -> 后端切换 -> 模组组合”顺序排查。
