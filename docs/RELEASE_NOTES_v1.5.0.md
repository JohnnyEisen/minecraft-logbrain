# v1.5.0 发布说明

**发布日期**: 2026-04-25

## 主线

- **启动可信化**: AI 初始化增加语义引擎预热与就绪校验，只在模型真正可用时标记就绪
- **交互清晰化**: 工具栏状态与分析流程联动，分析中/完成/失败三类状态明确区分
- **渲染诊断细化**: 覆盖层注入冲突、Vulkan 窗口占用、驱动模块崩溃、设备丢失、Shader 链接失败等模式

## 修复

- 模型可用性误报链路
- InvalidInjectionException 被通用候选误导 → 强规则优先
- 重复模组识别中的伪命名误报
- 渲染建议泛化 → 按根因差异化
